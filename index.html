关于这个项目

这是我的个人游戏作品集，使用纯Web技术（HTML5 Canvas + JavaScript）开发的休闲小游戏合集。

技术特点：

  • 纯原生JavaScript实现，无需额外框架
  • HTML5 Canvas 2D 渲染引擎
  • Web Audio API 动态音效系统
  • 响应式设计，完美支持PC和移动端
  • 本地存储主题配置，个性化体验
  • 调试面板，实时调整游戏参数
